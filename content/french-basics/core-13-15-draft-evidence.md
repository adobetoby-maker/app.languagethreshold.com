# French 101 Core 13–15 draft checkpoint

This bounded batch adds French target / English support authored **drafts** for Core 13–15. It is stacked on Core 10–12 draft PR #255. It does not register a course, alter stable lesson or progress IDs, or publish a runtime lesson. All review flags remain `false`.

The pinned source `source-english-core-13-15.json` captures the exact English objectives, 42 card/phrase meanings and 18 Reader meanings from `src/data/spanish-basics-core.json` and `src/data/spanish-basics-practice.json`. Both full-file SHA-256 values and the bounded source SHA-256 are checked by `python3 scripts/validate-french-basics-core-13-15-draft.py`. The validator also checks stage numbers, source provenance for every English pair, aligned readings, five lesson checks and listening-script status. Earlier French 101 validators through Core 12 pass on this branch.

The new lessons teach French **pouvoir + infinitive**, **avoir besoin de** versus **devoir + infinitive**, then **faire** alongside idiomatic *préparer le dîner* and *poser des questions*. Each has six aligned contextual lines, a specific speaking task and five recall/write/listening/comprehension checks. The Core 15 English source says friends ask questions “in Spanish”; the learner-facing French course says *en français* / “in French.” The exact original remains in `sourceMeaningEnglish` and `sourceNativeEnglish`. Core 14 has two source cards distinguished as masculine versus feminine “the/them,” but both map to French *les*. The second is marked `merge-with-order-7` so the eventual learner deck has one *les* card while retaining both source pairs for audit.
