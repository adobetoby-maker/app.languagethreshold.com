# French 101 Master 1–20 form practice — private draft

`private-form-practice-master-1-20-fr-en.json` is generated from the exact French→English `private-runtime-master-1-20.json` fixture by `scripts/build-french101-master-form-practice.py`. It pins the source SHA-256, stage-local lesson keys, Reader turn numbers, and stable prompt IDs. It remains `registered:false` and `reviewed:false`; no public course, audio, or learner progress changes.

The 96 author-selected bilingual Reader turns practice each Master lesson's contextual forms: introductions and register, requirements and substitutions, distribution, role versus temporary condition, past and current locations, repair and confirmation, habit versus exception, written replies, comparison, possession, dietary preferences, permission, task dependencies, interrupted plans, directions, progressive versus future, pronoun reference, event sequence, and integrated discussion. The source Reader lines contain role labels. The fixture retains each complete role-labelled line and speaker while making the typed answer the exact spoken utterance after the label. The source-pair test reconstructs every line exactly.

Local private French 101 Master manifests contain all 96 `audioDisplayText` keys and all 96 corresponding spoken utterances. This is text coverage only; listening approval and runtime audio routing remain separate. The `knownFrenchVariants` field contains the exact source utterance only and is not an exhaustive translation key.

Run `python3 scripts/build-french101-master-form-practice.py --check`, `python3 scripts/validate-french-basics-master-redesign-all-drafts.py`, and `node --test tests/language-form-practice.test.mjs tests/lesson-practice-kit.test.mjs` after source edits. The fixture test now covers 329 Foundation/Core/Master prompts. Qualified French review, runtime registration, audio playback, offline, browser/phone and V4 acceptance remain open.
