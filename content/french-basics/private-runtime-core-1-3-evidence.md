# French 101 Core 1–3 private curriculum fixture

This bounded pilot converts the existing source-pinned Core 1–3 drafts into a `ModuleCurriculum`-shaped private fixture. The stable module ID is `french-basics`, with lesson keys `french-basics:1` through `french-basics:3`. Its target is French and its support language is English. It is deliberately not registered in `CURRICULA` or any live route, and it makes no progress writes. Existing Spanish and Japanese IDs remain unchanged.

The source draft pins the English extraction and both original Spanish course files by SHA-256. The generator verifies those hashes and converts all 42 authored word/phrase pairs without deletion or paraphrase. All 42 cards fit the Core per-lesson limits: eight terms and six phrases per lesson, so the stage card indexes select every card and the backlog is empty. The 18 phrase pairs exactly match the 18 aligned Reader pairs. The sidecar also retains 21 dialogue lines, term dictionary entries, checks, French grammar notes, speaking prompts and inputs for See, Recall, Hear, Type, Say and Write. Hear/Say are scripts only; no recorded audio is claimed.

Validation: `python3 scripts/build-french-101-core-private-pilot-1-3.py`; `node --test tests/french-101-private-core-pilot-1-3.test.mjs`. The test verifies source hashes, exact card/Reader/dialogue/check/speaking pairs, six mode inputs, per-lesson Core word-count validation and isolation from the registered Spanish/Japanese courses. A full Core 30 stage validation is premature because this fixture contains only lessons 1–3.

This is an unreviewed private candidate (`reviewed:false`, `registered:false`). Independent French fidelity/curriculum review and qualified human review remain open; some source lines refer to studying Spanish and broad English glosses need editorial judgment. Runtime wiring, authenticated phone/offline checks, Japanese/Spanish regression acceptance and recorded French audio remain separate release gates.
