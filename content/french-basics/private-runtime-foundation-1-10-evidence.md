# French 101 Foundation 1–10 private runtime fixture

This fixture completes a **private structural pilot** for the ten French 101 Foundation lessons using four authored source batches. It preserves the stable `foundation-french-basics:1` through `:10` lesson keys and a distinct `foundation-french-basics` module ID. It is stored in `content/french-basics/private-runtime-foundation-1-10.json`, outside the live stage directory and manifest, with `privatePilot:true`, `registered:false`, `reviewed:false`, and no recorded audio. Spanish and Japanese course IDs, registered curricula and learner progress are untouched.

The stage-file portion contains curated 8–12 term and 4–6 phrase sets for each lesson and converts with the existing stage parser. The private sidecar preserves **all 289 exact authored French/English cards** plus 83 Reader dialogue pairs, term dictionary entries, speaking briefs and checks. It lists every selected stage-card index and every unselected backlog card. Inputs for See, Recall, Hear, Type, Say and Write are present; Hear and Say remain script-only. No original French/English pair is removed or rewritten. The four drafts, their Spanish sources and the curation plan are SHA-256 pinned.

The full `validateStageFile` structural check for `foundation-french-basics`/French returns **zero errors**. Focused tests verify hashes, stable and distinct language IDs, absence from the live manifest, stage conversion, exact pairs, all six mode inputs and no lost backlog cards. Passing this structural check does not establish linguistic quality, pedagogy, recorded pronunciation, offline behavior or app UI behavior.

Independent French fidelity/curriculum review and qualified human review, language-pair-safe production registration, actual See/Recall/Hear/Type/Say/Write and Reader/cards/dictionary/speaking UI acceptance, offline pack integration, speech recognition and feedback, recorded French audio, signed-in browser and phone testing remain open. This is not a released course or TestFlight build.
