# French Roofing private audio scope

This is an unsynthesized, exact-text inventory for the 60 French→English Roofing Supervisor draft lessons. It includes 983 French card-front placements and 646 French Reader-line placements, deduplicated to **1,381 exact strings**. A two-voice plan would require **2,762 clips** and 128,210 Unicode characters before any provider-specific billing calculation. The [machine-readable inventory](private-audio-scope-fr-en.json) records the source fixture hash, each exact text hash, all lesson occurrences, and the combined text hash `4d0be560dbe331767a80eedd67692c3ad8c625d0f7c83b505288d91b84ea55d4`.

The 60 speaking openings are deferred because they are interactive prompts with blanks or embedded English instructions, not fixed French speech lines. English support, mode instructions and unwritten AI replies are also excluded. `python3 scripts/build-french-roofing-private-audio-scope.py --check` fails if source text or the saved inventory changes without regeneration.

As of 2026-11-08, [Google's voice list](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types) lists `fr-FR-Chirp3-HD-Aoede` (female) and `fr-FR-Chirp3-HD-Charon` (male). At its [listed US$0.00003 per character rate](https://cloud.google.com/text-to-speech/pricing), the 128,210-character two-voice inventory has a nominal synthesis charge of about **US$3.85**, before retakes or taxes. Local Google Application Default Credentials obtain a token, but the Text-to-Speech voices API returns `PERMISSION_DENIED` because no quota project is configured. No paid synthesis request was made. A billing-enabled quota project with Text-to-Speech access is required for a bounded pilot.

`scripts/generate-private-course-hd-audio.py` defaults to a dry run and caps paid synthesis at 20 clips per call. Paid runs require the quota project and an approved aggregate exact-text SHA-256. The script verifies each exact row and aggregate hash, then stores the text, voice, locale, file hash, byte count and ffprobe duration in a private manifest with `listeningReviewed:false`. It does not publish audio. A dry run on this inventory planned 20 clips, 672 characters and a nominal US$0.0202, with no paid call.

All source lessons and this inventory remain `reviewed:false`, `registered:false`, `recordingsGenerated:false` and `listeningReviewed:false`.
