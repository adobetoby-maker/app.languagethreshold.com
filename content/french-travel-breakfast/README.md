# French Breakfast review packets

This directory archives the source-pinned French→English editorial packets for Foundation 1–10 and Core 1–14. The [packet index](review-packets/index.json) identifies one current review packet and its SHA-256 digest per lesson. Each lesson directory also retains the source snapshots, model prompts and outputs, local validator or builder, and a `CHECKPOINT.md` or `REPORT.md` with its remaining review decisions. The packet schemas differ; they have deliberately not been merged or projected into learner content.

These are **unreviewed drafts**. The independent source and structural checks passed for Foundation 1–10 and Core 1–14 (Core 2's `build_packet.py` check is recorded in its `REPORT.md`). This does not establish qualified French, cultural, food-domain, dictionary, audio, or device approval. All learner, audio, listening, scoring, progress, and release gates remain closed. No route, catalog item, deck, audio manifest, practice registration, progress key, or V4 asset consumes this directory.

The Core 1–14 Spanish Breakfast source is `public/lesson-content/es/travel-breakfast.json` at SHA-256 `8c00629a79532821ac7b554a4e0f828b25372500303b3dc70f9568c5aabb34cc`. Foundation packets pin their course and Reader snapshots separately; see each checkpoint and manifest. The older French #475 draft is a translation reference where mentioned, not the source of truth.

Review the specific caveats before any promotion: Foundation 5 has an English/Spanish source conflict on “eggs to order” versus *huevos al gusto* and must not be treated as a resolved paired card. Foundations 5–6 retain Spanish Reader verb paradigms without complete French counterparts. Foundation 6 has a source `usted`/`tú` inconsistency. Core 2's *café americano* versus “black coffee” and its Roman setting need a localization decision. Core 12 needs a France-specific bill, cover/service charge, and tip review; Core 13 needs *pan dulce* and future/politeness review; Core 14 needs *être pressé(e)*, *un americano*, and accepted answer variants reviewed. Each packet's checkpoint lists its other open questions.

Missing authored lessons are Core 15–30 and Master 1–20. Recorded French audio and per-clip listening review are missing for this packet set. Those gaps need tracked work before a course release. Source parity checks and AI critique do not set `reviewed:true`.
