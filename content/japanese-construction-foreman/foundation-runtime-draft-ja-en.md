# Japanese Foreman Foundation 1–10 runtime draft

`foundation-runtime-draft-ja-en.json` is a deterministic **private draft** built from the three pinned Foundation source slices. Regenerate it with `python3 scripts/build-japanese-foreman-foundation-runtime.py`, then run `python3 scripts/validate-japanese-foreman-foundation-pilot.py` and `python3 tests/japanese-foreman-foundation-runtime.test.py`.

The bundle contains ten stage-local lessons, six-mode input labels, aligned Reader sentences, grammar focus and examples, speaking mission inputs, cloze checks, 163 deduplicated cards and 163 matching dictionary entry drafts. The `es` field in source words follows the app's historical “target language” convention and contains Japanese, not Spanish. The bundle explicitly identifies `Japanese:English` and uses `foundation-construction-foreman-ja-en` for the course, lesson, Reader, speaking, card and dictionary identities. The English source module remains `foundation-construction-foreman`; it must not be used as a Japanese learner progress key. Spanish course and learner records are untouched.

This bundle is deliberately under `content/`, with no public manifest, catalog, stage-file, offline-pack or speaking-mission registration. The current stage cache is keyed by `moduleId`, so putting a Japanese file under the Spanish ID would risk mixing language data. The distinct Japanese ID avoids that collision when a future fully validated course is registered. Promotion still requires a pair-specific catalog module and end-to-end testing of route, cache, lesson progress, Reader, cards, dictionary, speaking, six modes and offline behavior.

Review status is unchanged: Foundation 1–3 received scoped Fable and Opus AI rechecks in the source pilot; Foundation 4–6 Claude CLI review attempts ended at the USD 2 budget before findings; Foundation 7–10 have no independent AI review. None has qualified fluent Japanese, construction or safety approval. All `reviewed` flags remain false. This derivation does not constitute linguistic or domain review. Audio has not been produced or checked; no web release, iPhone/Watch build or TestFlight acceptance is claimed. Before release, complete Fable/Opus review and material fixes for 4–10, qualified human/domain review of all ten, Japanese HD recording and listening checks, then authenticated browser/phone/offline and V4 tests. The Japanese 101 and Spanish courses retain their existing identities and progress.
