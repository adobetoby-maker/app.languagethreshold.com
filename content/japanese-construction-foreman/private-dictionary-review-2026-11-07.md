# Japanese→English Foreman private dictionary inventory

Source: the 60 private Foundation/Core/Master runtime inputs stacked through draft PR #290, commit `9b4a6514c363ebae1aeed471f6020762db09f6ef`. Run `python3 scripts/build-japanese-foreman-private-dictionary.py` to rebuild the inventory and `--check` to verify it. The JSON records SHA-256 for each source file and retains each source dictionary ID, lesson occurrence and card ID. It is **unregistered**, `reviewed:false`, and does not change the live dictionary or any learner progress.

There are 1,075 word placements across 60 lessons and 1,016 exact Japanese/English term-sense pairs after deduplication. The 10/30/20 stage placements are 163/450/462. Eleven Japanese headwords have more than one English gloss. Some are article or case variants (for example `ヘルメット` “Hard hat” / “the hard hat”); others require a real sense distinction (`じょうきょう` “Condition” / “Status”, `石膏ボード` “the drywall” / “the drywall sheets”). They remain separate because a normalization would erase the authored sense or change stable IDs. Each entry retains its source ID even when it recurs in another lesson.

The source provides `term` or `phrase`, but no verified part of speech or inflection model. The inventory leaves those fields `null` on all 1,016 entries. Qualified Japanese and construction reviewers must resolve gloss variants, readings, register, grammar/POS, inflected forms, and specialist meanings before publication. The Master 2 garage-deck/deicing-water claim and other safety/code terms remain blocked by the existing specialist review ledger; this inventory is provenance, not endorsement. No audio or runtime registration is implied.
