# Japanese→English Roofing Supervisor draft

Foundation 1–10 and Core 1–30 are private authored drafts for a Japanese equivalent of the Spanish Roofing course. The previous Japanese program coverage snapshot did not include Roofing among its 56 catalog-compatible tracks; this is a newly proposed Spanish-parity analogue, not one of the originally counted 55 remaining tracks.

The English objectives and progression are pinned to the Spanish Roofing curriculum and its English Reader translations. The Japanese passages and grammar are adapted for Japanese, with stable `foundation-roofing:N:ja-en` and `roofing:N:ja-en` lesson IDs. The source objective for Foundation 3 names Spanish *ser* and *estar* only as provenance; the learner-facing lesson teaches Japanese identity and condition constructions. Core 30 adapts the source objective “in Spanish” to Japanese while retaining that wording only as source provenance. Core 1–30 preserve all 440 English card anchors, 251 aligned Reader lines, and 150 English verb-example anchors; the Japanese examples are authored drafts.

All content is `reviewed:false`, `registered:false`, with no audio. A fluent Japanese reviewer should check natural construction terminology, especially シングル材, フルハーネス, ルーフィング, 水切り板金, 棟包み材, 竪どい, 墨線, and measurement phrasing. A qualified roofing reviewer should check technical claims separately, including the English F5 “work fast because it is hot” line, F8's absolute wet-roof statement, Core 2's drip-edge sequence, Core 3's step-flashing/valley/chimney instructions, Core 4's ventilation/drainage placement, Core 7–10's tear-off, deck-repair, debris-handling and tarp sequence, and Core 11–12's layout and six-inch stagger example, Core 13's drip-edge order, Core 14's guide overlap example, and Core 15's valley membrane sequence, and Core 16–18's nail placement, manufacturer-specific fastening pattern, and overdriven-nail correction, plus Core 19's sidewall flashing sequence and Core 20's product-dependent ridge-cap cutting. Core 21's lanyard-ground-clearance phrase and tie-off wording, Core 22's competent-person designation and fall-distance claim, and Core 23's weather/footing phrasing, Core 24's direct heat-exhaustion terminology and site-plan claim, Core 25's debris exclusion procedure, and Core 26's deck-repair documentation language, Core 27's pipe-boot and penetration terms, Core 28's cleanup claims, Core 29's punch-list language, and Core 30's full-day sequencing also need qualified review.
