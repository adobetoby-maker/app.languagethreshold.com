# Japanese Breakfast private audio scope

This is an unsynthesized, exact-text inventory for 60 Japanese→English Breakfast & Cafés draft lessons. The source covers 833 Japanese card placements and 577 Japanese Reader-line placements, deduplicated to **1,180 exact strings**. A two-voice `ja-JP` Chirp 3 HD plan using [Aoede and Charon](https://docs.cloud.google.com/text-to-speech/docs/list-voices-and-types) requires **2,360 clips** and **28,030 input characters**, before retakes. At the [provider's listed US$0.00003 per character rate](https://cloud.google.com/text-to-speech/pricing), the nominal synthesis charge is about **US$0.84**; actual billing and taxes depend on the project. The [machine-readable inventory](private-audio-scope-ja-en.json) pins each exact text, SHA-256, source occurrence and source-file hash. Rebuild or verify it with `python3 scripts/build-japanese-travel-breakfast-audio-scope.py --check`.

This scope excludes English support, mode instructions, interactive speaking openings and unwritten AI replies. All source lessons and this inventory remain `reviewed:false`, `registered:false`, `recordingsGenerated:false` and `listeningReviewed:false`. Exact Japanese language review, audio listening review and playback/offline/native acceptance remain open. No learner-facing audio or progress changed.

On 2026-11-08, local Google Application Default Credentials could obtain a token, but the Text-to-Speech voices API returned `PERMISSION_DENIED` because no quota project was configured. No paid synthesis request was made. A billing-enabled quota project with Text-to-Speech access is required before a bounded recording batch can run.

`scripts/generate-private-course-hd-audio.py` provides a resumable 20-clip maximum per run, defaulting to a dry run. A paid run additionally requires the quota project and the approved aggregate exact-text SHA-256. It verifies row and aggregate hashes before requests, then records each MP3's exact text, voice, locale, file hash, size and ffprobe duration in a private manifest. Its manifest keeps `listeningReviewed:false`; synthesis never enables playback or marks review complete. A dry run on this inventory planned 20 clips, 184 characters and a nominal US$0.0055, with no paid call.
