# Japanese Breakfast Foundation 8 audio candidates

These 52 `ja-JP` MP3s are inert, source-only review assets for the 26 card and Reader placements in [the Foundation 8 source-setting candidate](../source-setting-candidate.json). Each placement has a separate female and male recording, including the repeated exact sentence. The source SHA-256, every placement ID and Japanese text, voice identity, file hash, byte count, duration and decoded-signal measurement are pinned in `scope.json`, `manifest.json` and `verification.json`. Run `python3 validate.py` on a machine with `ffmpeg` and `ffprobe` to check the assets against the current source packet. No app, owner page, public audio route, native bundle or offline pack imports this folder.

The quota project was `project-91661021-fb2d-4524-b9f`. The batch submitted 802 characters using `ja-JP-Chirp3-HD-Aoede` and `ja-JP-Chirp3-HD-Charon`, with estimated gross cost $0.02406 at [Google Cloud's current $30/million-character Chirp 3 HD rate](https://cloud.google.com/text-to-speech/pricing). This is an estimate; the actual invoice and any free-tier offset are unknown. Two recordings had excess leading silence. Their original files remain in the private working folder, and this archived pair has 0.35 and 0.25 seconds trimmed, respectively. The changes are in `signal-trims.json`. Final verification has zero signal flags.

Open `listening-review.html` from this folder to play and assess **each exact clip separately**. Its pending controls do not write approval. Every clip has `listeningReviewed:false`; all registration, bundling, learner, scoring, offline, progress and release gates stay closed. The packet's text and IDs were unchanged when explicit top-level `reviewed:false` was added; `source-repin-audit.json` records that provenance change. Qualified Japanese, Oaxaca food/allergy and saved-item review remain before text freeze or release. Any later exact-text or placement change requires a fresh recording identity and listening decision.

The lesson text comes from the repository's pinned source and Japanese candidate. Synthesis used Google Cloud Text-to-Speech named voices. The repository contains separate Japanese 101 pilot MP3s and an inert F4/F9 review archive; no repository rule was found that bars source-only generated audio evidence. [Google Cloud service terms](https://cloud.google.com/terms/service-terms) are linked for provenance; this packet does not assert legal approval.
