# Japanese→English Lunch & Casual Dining, private Foundation 1–6 draft

This is an unregistered, unreviewed partial course draft. It maps the first six source objectives from `src/data/core60/es/foundation-travel-lunch.json` without borrowing Spanish vocabulary or grammar. Stable IDs are `foundation-travel-lunch:1:ja-en` through `:6:ja-en`. The source file and each objective are pinned by SHA-256 in the two lesson batches.

The lessons teach daytime greetings and lunch words, yen/prices with Japanese counters, food qualities and seat availability without imposing the Spanish `ser`/`estar` distinction, availability/want/need, going and ability, then eating/sharing/payment without Spanish person conjugations. They have 82 contextual cards, 55 bilingual Reader turns, six speaking scenes, and 36 distinct See/Recall/Hear/Type/Say/Write prompts. Each mode activity cites its exact card. Run `python3 content/japanese-travel-lunch/verify-private-foundation.py` to check source identity, stage IDs, model/card links, all six modes per lesson, and closed release flags.

Remaining work includes Foundation 7–10, Core 1–30, Master 1–20, qualified Japanese review, contextual dictionary senses, recorded and listened audio, exact-pair runtime/Reader/speaking/offline integration, browser/phone/native acceptance, and production verification. `reviewed`, `registered`, and `readyForLearner` remain false; no learner progress keys or production assets change.
