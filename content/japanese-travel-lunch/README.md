# Japanese→English Lunch & Casual Dining, private Foundation 1–10 draft

This is an unregistered, unreviewed Foundation stage draft. It maps all ten source objectives from `src/data/core60/es/foundation-travel-lunch.json` without borrowing Spanish vocabulary or grammar. Stable IDs are `foundation-travel-lunch:1:ja-en` through `:10:ja-en`. The source file and each objective are pinned by SHA-256 in the three lesson batches.

The lessons teach daytime greetings and lunch words, yen/prices with Japanese counters, food qualities and seat availability without imposing the Spanish `ser`/`estar` distinction, availability/want/need, going and ability, eating/sharing/payment without Spanish person conjugations, menu questions, food preferences, payment requests, and repair language. They have 135 contextual cards, 91 bilingual Reader turns, ten speaking scenes, and 60 distinct See/Recall/Hear/Type/Say/Write prompts. Each mode activity cites its exact card. Run `python3 content/japanese-travel-lunch/verify-private-foundation.py` to check source identity, stage IDs, model/card links, all six modes per lesson, and closed release flags.

Remaining work includes Core 1–30, Master 1–20, qualified Japanese review, contextual dictionary senses, recorded and listened audio, exact-pair runtime/Reader/speaking/offline integration, browser/phone/native acceptance, and production verification. `reviewed`, `registered`, and `readyForLearner` remain false; no learner progress keys or production assets change.
