# Spanish Cognates · Core 60

Spanish target, English support only. State: **mapped 60 draft**, instructor review pending.

- Foundation 1–10: recognizing familiar word families, Spanish stress, spelling and gender.
- Core 1–30: additional patterns, false friends, contextual meaning, regional cautions and clarification.
- Master 1–20: longer application/repair cases. These deliberately continue twenty earlier scenes with six additional aligned sentences each; they are not sixty unrelated certified proficiency levels.

`foundation-core.txt` contains forty original bilingual scenes with eight explicit glossary terms and six aligned sentences each. `master.txt` contains twenty original continuations, each linked to one scene and adding four glossary terms and six sentences. The resulting Master lessons contain twelve terms, eight phrase cards and twelve aligned sentences.

Run `python3 scripts/build-spanish-next.py` to derive all three stage files, the Core curriculum, practice/check data, public lesson content and content index. The normal app build regenerates Reader/library shards, dictionary vocabulary index and source fingerprints. Existing lesson identities remain unchanged.

Every lesson has See, Recall, Hear, Type, Say and Write, three accent-sensitive contextual cloze questions, exact Reader ownership, module-deck integration and its own speaking mission. The cloze checks are practice evidence and do not certify real-world language proficiency. Verb reference models and existing lesson verb games are available through the shared lesson kit.

No formal exam bank, registered offline lesson download or human-performed audio is added. Female/male Google Chirp 3 HD recordings are complete, with nonzero durations verified by ffprobe and both voices played through the web audio route on desktop and iPhone-sized Chromium. Human listening review remains pending. Native V4 has a separate existing Cognates course; this web course does not claim a new TestFlight release.

See `sources.json` for original-content provenance, dictionary spot checks and review limits. The bundled source audit validates wiring and content structure, not full linguistic quality or installed-device behavior.
