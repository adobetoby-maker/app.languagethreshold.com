## Connection map

- **Working after local build:** Reader word → Word Card → structured Tutor context.
- **Working after repair:** Reader save → language-owned My Vocab → same-language Flashcards sync.
  Switching languages changes the visible personal list without relabelling or erasing another
  language, and local/remote merges union each language independently.
- **Working:** Module activation → module-specific navigation/content.
- **Working:** Learning activity → Dashboard counters and progress.
- **Aspirational, not claimed in UI:** Flashcard weakness → Speak/Grammar recommendation; automatic
  Reader grammar extraction.

The `TabKey` union contains 31 registered tabs. Word Card, My Vocab, onboarding, account saving,
the module picker, Language Match, and Leaderboard are learner-facing surfaces rather than
registered tabs, and are inventoried separately above.
