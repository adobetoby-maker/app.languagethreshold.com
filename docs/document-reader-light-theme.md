# Document Reader light palette

Selecting **Light** in the existing theme switch uses the Document Reader’s warm ivory paper, white cards, navy text and teal actions throughout surfaces that use the app’s shared color tokens. Gold remains the brand detail; tinted teal marks hover and selection states.

| Role                            | Color     |
| ------------------------------- | --------- |
| Page background                 | `#F6F2E9` |
| Cards and menus                 | `#FFFFFF` |
| Text                            | `#132737` |
| Primary actions and focus rings | `#146E73` |
| Secondary surfaces              | `#E8EFEB` |
| Muted text                      | `#52616A` |
| Borders                         | `#D4DED7` |
| Gold details                    | `#D7A63A` |
| Gold text on light backgrounds  | `#86600F` |

The default theme and stored Light/Dark preferences are preserved. Dark mode explicitly retains its prior brand tokens. The standalone Documents workspace already uses this palette. Components with their own fixed colors retain those colors.

Review the dashboard, module cards, lesson reading surfaces and settings in Light mode, then switch to Dark to compare. Teal primary buttons use white text; the darker gold ink token is used for gold text on paper.
