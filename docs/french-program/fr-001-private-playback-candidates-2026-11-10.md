# French pronunciation private playback candidate map

The [private candidate map](../../content/french-pronunciation/private-playback-candidates-fr-en.json) covers the 60 authored French→English pronunciation draft lessons. Its builder rechecks all seven source-pinned batches and 1,778 MP3 files through the full-course verifier, then cross-checks the decoded-signal report. These batches contain 1,660 unique exact-text/voice pairs. For 1,560 pairs, there is exactly one unflagged byte identity, so the map records a **technical candidate** with its batch, file name, voice, hash, and duration. It withholds 100 pairs: 80 have different unreviewed takes and 20 have no unflagged take.

Run `python3 scripts/build-french-pronunciation-private-playback-candidates.py --check` after any source, manifest, signal, or MP3 change. The map fails closed on stale hashes or coverage.
