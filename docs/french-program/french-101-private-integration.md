# French 101 private integration adapter

The review-only adapter in `src/data/private-french-101-candidate.ts` reads the three source-pinned fixture objects supplied by a test or review harness. It prepares exact French-target/English-support catalog entries, converts Foundation and Master through the shared Core 60 stage converter, caches the three 10/30/20 curricula by pair and stage ID, and exposes lesson-scoped Reader, card, dictionary, speaking, and six-mode sidecars. It proposes exact-pair offline pack IDs without adding them to the shipped allowlist. All 60 stable lesson/progress IDs are unchanged.

The release constant is `false`, and `releasedFrench101()` always returns `null`. No production route imports this adapter, no French 101 module or stage is added to the shipped catalog or stage manifest, and no offline pack is registered. The tests assert that Spanish/Japanese curricula and the public module list remain unchanged. This is an integration seam for review, not a learner-facing course.

Before enabling any route, complete [FR-008 / issue #180](https://github.com/adobetoby-maker/app.languagethreshold.com/issues/180): French editorial and qualified human review, 27 dictionary sense/alias decisions, Master 11 English support edit, grammar/prerequisite review, recorded audio validation, actual offline pack/download checks, authenticated phone and browser tests, native-app identity/device checks, and a verified production release. Preserve existing progress values under the three stable stage keys. The [readiness audit](french-101-private-readiness-2026-11-07.md) has the current counts and evidence.
