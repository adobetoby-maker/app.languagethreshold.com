# Japanese 101 private six-mode authoring

`content/japanese-basics/private-foundation-six-mode-prompts-ja-en.json` authors a distinct See, Recall, Hear, Type, Say, and Write task for each of the ten Foundation lessons. Each task points to an exact dialogue turn in the existing Japanese→English lesson source. The deterministic builder emits `private-foundation-six-mode-runtime-preview-ja-en.json` with the exact Japanese target text, English meaning, stable stage-local key, and source hashes. The preview has 60 authored activities and retains `reviewed:false` and `registered:false`.

Run `node scripts/build-japanese101-foundation-six-mode-preview.mjs --check` and `node --test tests/japanese101-foundation-six-mode-preview.test.mjs` to verify the 10/60 counts, source identity, six distinct modes per lesson, unique activity IDs, exact dialogue pairs, and private gates. TypeScript checking also passes. These prompts are a review candidate; they are not registered in the learner UI, and no progress or released lesson identity changes. Fluent Japanese review, browser/phone mode acceptance, audio listening review, and native release validation remain open.
