# Japanese 101 private katakana supplement

Each sign has a read prompt and a write prompt. The units cite exact Japanese→English term pairs from Foundation, Core, and Master: `ノート`, `けしゴム`, `アメリカ`, `ドア`, `ペン`, `メニュー`, and `グループ`. Source file SHA-256 values and stage-local lesson keys keep those examples tied to the existing course.

This is script-specific supplemental content, not five additional numbered Core 60 lessons. The separate `content/japanese-basics/private-katakana-contrasts-ja-en.json` now adds three source-linked units and seven recognize/write activities for dakuten and handakuten (`ドア`, `けしゴム`, `ペン`), small ュ (`メニュー`), and the long-vowel mark (`ノート`, `グループ`). Each example pins an exact Japanese 101 lesson term and English meaning; the original lesson text is unchanged. `JapaneseScriptPractice` provides a private read/write input flow for the 46 basic cards, with exact-script checking in `src/lib/japanese-script-practice.ts`; no lesson or route imports these supplements. No recorded audio, offline pack, or progress key is installed. Qualified Japanese review must assess the examples, visual confusables, sequencing, and phone/native presentation. `registered:false` and `reviewed:false` remain true.
