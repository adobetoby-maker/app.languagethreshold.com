# Japanese 101 speaking runtime preview

The private exact Japanese→English fixture `content/japanese-basics/private-speaking-runtime-preview-ja-en.json` applies the authored lesson-specific speaking role and goals to the **actual 60 live lesson mission shapes**: Foundation 10, Core 30, Master 20. It is generated by `scripts/build-japanese101-speaking-runtime-preview.mjs` from the current speaking catalog and the three source-pinned private speaking candidates.

The preview preserves each mission ID, scenario ID, source objective ID, opening, language/locale, vocabulary, first two source prompts, objective IDs, and existing safety fields. It changes only the speaking role, third source prompt, speaking context, and objective descriptions. The deterministic check and focused test verify 60/60 coverage and these identity invariants.

The fixture remains `reviewed:false` and `registered:false`. It is not imported into the learner runtime or native app, and it changes no saved progress. Qualified Japanese instructional review, all remaining recorded audio and listening checks, browser/phone acceptance for the changed missions, and independent V4 acceptance remain open before release.
