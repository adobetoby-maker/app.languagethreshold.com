# Module placement

Placement is available from every course lesson overview and is linked from Exams. It follows the Roofing pattern of mixed question formats and lesson-based results, with a separate independent-study credit flow.

## Learner flow

The test walks available Foundation, Core and Master lessons in order. Each five-lesson block checks every lesson with one meaning question and one typed contextual cloze. The block must score at least 80% overall and 80% on typed answers. The first weak block becomes the recommended starting point. Only earlier passed blocks are eligible for credit. Learners can open the recommendation without credit, explicitly confirm completion credit, pause and resume in the same browser tab, or retake with a new draw.

Core Basics use their authored grammar, conjugation and cognate checks. Other courses use the exact pair's glossary and aligned lesson examples. Choice questions cannot directly expose the same lesson's typed answer. Accents matter; case and punctuation do not. This assesses recognition and contextual written recall, not speech or professional certification. Source lessons retain their original human-review status.

## Progress and boundaries

- Credit updates independent `core30Log` and the contiguous `lessonProgress` count for the exact module and target/support pair.
- Each credited lesson records its attempt ID, version and timestamp. Cloud merge preserves that provenance. Practice visits, XP, streaks and team activity are not fabricated.
- Existing progress is preserved; duplicate application is idempotent. Managed enrollments reject this action.
- Paused attempts use account/pair/course-scoped session storage. A fingerprint change resets stale answers rather than grading against a changed source.
- Missing or mismatched materials stop coverage. No completion is granted for untested lessons or a borrowed language track.

## Coverage and checks

`docs/module-placement-coverage.json` is generated by `node scripts/audit-module-placement.mjs --write`. The November 2 source covers all 67 Spanish-for-English modules, including all seven Core Basics paths, plus Military, OR EVS and FMG in English for Spanish speakers. Other English tracks do not yet have complete Foundation material for placement.

Run `node --test tests/module-placement.test.mjs tests/core30-scope.test.mjs`, the repository unit/type/lint/build gates, and `npx playwright test --config placement.playwright.config.ts` against the local dev server. The focused browser suite checks desktop and phone recommendation, no-credit behavior, opt-in credit, progress persistence, resume, 101/102/cognates/Roofing questions, and real runtime coverage of all Spanish courses. The ordinary pre-push smoke suite checks existing learning paths.

Placement is an addition to the existing A/B/C and supervised exams; it does not change their banks, approval gates or scoring.
