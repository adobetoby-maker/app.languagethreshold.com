# Language Threshold native apps

Open `App/App.xcodeproj` after running `npm ci` from the repository root. The App scheme embeds the paired watchOS application. Signing, architecture builds, preview testing, permissions and real-device acceptance are documented in [Apple Watch push-to-talk](../docs/apple-watch-push-to-talk.md).

Do not uninstall or clear learner data to test an update. No signing credentials, audio recordings or derived build products belong in this folder.
